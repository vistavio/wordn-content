# Word'n content packs

New rooms, projects and products for the game Word'n, downloaded by the app without a store update.
Data and pictures only (no code). Built and published with `tools/build_content_pack.py` in the game repository.

- `manifest.json`: the list of packs (read by the game via raw.githubusercontent.com)
- `<id>_v<version>.zip`: the packs (downloaded via jsDelivr, GitHub as fallback)
